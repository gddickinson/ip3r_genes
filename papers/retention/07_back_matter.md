## Data availability

Every table and figure this paper reports is committed under `results/`
(`genome_manifest.tsv`, `s5_baits/`, `genome_ledger/`, `loss_dynamics/`,
`loss_counts/`, and the contiguity and panel halves of `methods/`), with a
SHA-256 for each file in `papers/retention/deposit_manifest.tsv`. Genome
assemblies are retrievable from NCBI by the accessions in
`results/genome_manifest.tsv`. Per-genome sweep output (miniprot GFF, rescue
output and a summary per genome) is regenerated by
`python scripts/s5_run_sweep.py` and is listed, with the command for each
bulk class, in `papers/retention/deposit_notes.md`.

## Code availability

The analysis scripts are in `scripts/`. `python scripts/s26_assemble.py
--paper retention` rebuilds this paper from the committed tables, re-checks
every load-bearing number against its source table, and exits non-zero if
any has moved.

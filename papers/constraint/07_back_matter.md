## Data availability

Every table, alignment, tree, figure and report this paper rests on is in
the deposited archive, listed file by file with its size and SHA-256 in
`papers/constraint/deposit_manifest.tsv`. The primary results are
`results/selection/` (codon models, RELAX, the codon alignment and its
validation) and `results/constraint/` (the per-residue tables, the orthologue
sets, the variant tables and the painted structures). The per-residue
deliverable is one table per human paralogue,
`constraint_<gene>_<accession>.tsv`, giving every residue in its own UniProt
numbering with four conservation layers, the occupancy each is conditional
on, its element, and whether it is a measured IP₃ contact, filter or gate
residue; `variants.tsv` joins the same columns onto every harvested ClinVar
record. These scores stratify variants of uncertain significance against the
labelled variants of the same gene. They are not pathogenicity calls and
should not be used as such. All primary data are public: genome assemblies
from NCBI Datasets, protein sequences from UniProt, the structure 6DQN and
the painted cryo-electron microscopy entries from the RCSB Protein Data Bank,
and variant records from ClinVar.

## Code availability

Every analysis is regenerated by the scripts in the repository
(`scripts/s9_*.py`, `scripts/s17_*.py`), each of which runs its constructed
negative controls before writing anything. This paper is rebuilt by
`python scripts/s26_assemble.py --paper constraint`, which re-verifies every
load-bearing number in it against the committed tables.
